Decision record · v1.2 · 2026-11-28

Resolved design decisions

  • Pricing scope: TASKS.price_id remains the per-turn default (spec EXEC-02, one model per turn). Every MODEL_CALLS row now stores its own price_id and rate snapshot, so historical bills no longer depend on the price catalog.
  • Rate unit: per_1m_tokens, matching billing.py's division by 1,000,000. Cached tokens are a subset of input tokens and are never double-charged. Cost uses Decimal calculation and NUMERIC(24,12) storage; budget currency is USD, matching the selected price version.
  • User ownership: TASKS.user_id removed. Ownership is derived from CONVERSATIONS.user_id only, so a task cannot belong to a different user than its conversation.
  • Tool grants: grant_id is mandatory for every tool call. Unselected material tools are recorded as explicit denials; delegated role tools carry a predefined EXEC-01 grant and are not exposed to the user grant API.
  • Grant scope: sub-agents inherit the turn's task-level grants; run-level grants were not adopted because spec MAT-04 defines grants at turn+tool scope.
  • Not adopted / unverified: URI + checksum for large MATERIALS.content (no requirement found in spec); argument masking and retention for TOOL_CALLS.arguments (no rule found in spec or code - needs security owner).
