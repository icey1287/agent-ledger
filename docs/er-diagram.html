Decision record · v1.2 · 2026-11-28

Resolved design decisions

  • Pricing scope: TASKS.price_id is the default per-turn price. Each MODEL_CALLS row stores its own price_id and rate snapshot, copied from agent_runs.price_id or the task default, so historical bills do not depend on the catalog.
  • Rate unit: per_1m_tokens, matching the /1,000,000 divisor in billing.py. Cached tokens are a subset of input tokens and are never double-charged. Cost uses Decimal and NUMERIC(24,12); budget currency is USD.
  • User ownership: TASKS.user_id is retained as a deliberate redundancy because the subscription composite foreign key depends on it. Trigger trg_tasks_owner enforces equality with CONVERSATIONS.user_id at write time.
  • Tool grants: grant_id is mandatory for every tool call. Unselected material tools are recorded as explicit denials; delegated role tools carry a predefined EXEC-01 grant.
  • Grant scope: sub-agents inherit the turn's task-level grants; run-level grants were not adopted because spec MAT-04 defines grants at turn+tool scope.
  • Not adopted / unverified: URI + checksum for large MATERIALS.content (no requirement found); argument masking and retention for TOOL_CALLS.arguments (no rule found in spec or code - needs security owner).
