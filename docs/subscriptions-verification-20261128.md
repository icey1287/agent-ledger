# 订阅功能交付与验证

2026-11-28，基于数据库约束修复提交 0d66e63。

## 功能

新增套餐、订阅、任务资格与历史关联，关系表从 11 张扩展为 13 张。支持 7 天体验与 30 天标准演示套餐、开通、有效期、立即取消、到期后重新开通、历史快照和用户隔离。开通不收取套餐费用，不自动续费，不赠送模型服务商余额。

新消息和兼容任务入口均检查订阅。并发开通按用户行锁串行，并由部分唯一索引防止两条 active 记录；重复开通同一有效套餐不延长有效期。任务通过复合外键记录同用户订阅。历史任务 subscription_id 保持空，不伪造开通记录。
