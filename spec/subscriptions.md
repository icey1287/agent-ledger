# 套餐与订阅

- 提供 7 天体验与 30 天标准演示套餐；开通不收取真实费用，不自动续费，不赠送供应商余额。套餐展示价与模型调用费独立。
- 登录用户可开通、查看历史、立即取消自己的订阅。有效期使用服务器 UTC，区间为 starts_at <= now < ends_at。取消立即阻止新任务，已接纳任务继续执行与结算。
- 同一用户最多一条 active 记录；到期状态按时间派生。再次开通时将到期记录转 expired 并插入新记录；有效期内同套餐重复请求返回原记录，不延长有效期，换套餐须先取消。
- 新任务必须有有效订阅，包括兼容 /api/tasks 入口；管理员无豁免。创建任务记录 subscription_id，用复合外键约束订阅与任务用户一致。旧任务可为空，继续可读，不补造历史订阅。
- 开通时保存套餐名称、展示价与币种快照；既有订阅不随套餐修改而改写。停用套餐阻止新开通，不撤销既有权益。
- 开通、取消、新任务资格检查均先锁用户行，再按原顺序锁对话/任务，保证并发状态有确定顺序；不在外部模型请求期间持锁。
- 无订阅、已取消或到期时返回明确错误，页面提供订阅入口；开通/取消需要登录与 CSRF，不能操作其他用户订阅。

验收覆盖：无订阅拒绝且无模型调用、开通与幂等、并发开通唯一、到期/取消阻止新任务、续订生成历史、跨用户拒绝、旧记录迁移、订阅归属外键、前端状态与任务绑定。
