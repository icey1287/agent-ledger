# 用量与计费

## 功能范围

按模型实际返回的用量与固定价格版本记录每次调用费用，按轮汇总，执行预算停止和未知用量核实。业务不包含订阅、积分、充值、周期额度、预算预留或支付结算。

## 功能要求

- **BILL-01 调用账目**：每次模型调用保留模型、价格版本、调用状态、原始 usage、输入 / 输出 / 缓存 token 和费用。模型与价格可通过所属执行关联；历史账目不随当前费率改变。
- **BILL-02 精确计算**：费用使用精确十进制计算和存储，传输金额使用十进制字符串。缓存 token 属于输入 token 子集；已包含在供应商输出计数中的推理 token 不重复相加。
- **BILL-03 未知用量**：缺失 usage、非法计数或缓存计数存在但缺少对应单价时，费用保留未知值，不能以零或估算值代替。停止本轮，显示已知费用小计和待核实标识。
- **BILL-04 软预算**：预算为每轮停止后续调用的阈值。调用前检查累计已知费用；调用后记录费用并决定是否允许继续。最后一次调用允许超过预算；若已经形成完整最终回复则可完成，否则在预算状态停止。界面须说明最后一次调用可能超额。
- **BILL-05 不确定调用**：超时等不能证明未产生用量的失败进入待核实，不自动重试。仅在供应商明确拒绝且可确定未产生用量时，记录已知零用量的失败调用。
- **BILL-06 补录**：管理员依据可靠的供应商用量或账单记录，补录输入、输出及缓存 token；核实依据必填，保存操作者与时间，并按原价格版本计算费用。仍在进行中的调用不能补录。
- **BILL-07 幂等与状态**：重复补录已经确认的调用不得重复计费或覆盖已确认账目。本轮未决用量全部确认后解除待核实标识，保留中断状态，不自动恢复执行。
- **BILL-08 展示**：每轮可查看逐次调用费用、已知用量和费用小计、预算与价格说明；未知值明确标识。执行失败、停止或重启不能抹去已经确认的费用。

## 计费公式

`费用 = ((输入 token − 缓存 token) × 输入单价 + 缓存 token × 缓存单价 + 输出 token × 输出单价) / 1,000,000`

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 输入 1,000、其中缓存 200，输出 100；单价分别为 0.50、0.10、2.00 | 费用为 0.00062 USD，缓存输入不重复计费 |
| 调用前低于预算，返回后超过预算且模型仍需继续调用 | 保存超额费用，后续调用停止 |
| 最终回复所在调用使费用超过预算 | 回复可完成，展示实际费用和预算 |
| usage 缺失、非法或超时未返回可靠用量 | 费用为未知，不记零，不自动重试 |
| 管理员提交可靠用量与核实依据 | 使用历史价格计算，保留补录审计信息 |
| 对同一调用重复补录 | 费用与记录数量不增加，已确认结果不被改写 |
| 普通用户补录，或对在途调用补录 | 请求被拒绝 |
| 用户停止或服务中断前已有成功调用 | 已确认用量与费用仍可查询 |
