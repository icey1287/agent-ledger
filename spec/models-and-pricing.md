# 模型与价格管理

## 功能范围

管理员维护同一模型提供商下的可选模型与价格版本；用户为每轮消息选择模型。

## 功能要求

- **MODEL-01 模型目录**：模型具有唯一供应商标识、显示名称和启用状态。用户只可为新一轮选择已启用模型；管理员可查看全部模型并新增、编辑显示名称或切换启用状态。
- **MODEL-02 标识稳定**：已有模型的供应商标识不可改写；使用不同标识时新增模型。停用不删除历史执行和调用记录，不改变已创建轮次固定的模型。
- **MODEL-03 价格字段**：每个价格版本包含币种、普通输入单价、输出单价、可选缓存输入单价、价格说明和可选来源。单价按百万 token 表达，使用非负精确十进制；不接受 NaN 或无穷值。
- **MODEL-04 版本固定**：新轮次固定所选模型的最新价格版本。修改费率、币种或价格说明时生成新版本；已有版本保持不可变。并发编辑不得生成重复版本号。
- **MODEL-05 提供商配置**：Base URL 与 API Key 在后端配置，浏览器不接触密钥。提供商未配置时明确提示并拒绝启动模型执行。
- **MODEL-06 演示费率**：费用记录可使用配置的演示费率。界面展示价格说明，明确其与供应商实际扣费的区别；具体提供商、模型名和默认费率属于运行配置，不固化在功能规则中。

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 管理员新增唯一模型并配置价格 | 用户可选择已启用模型，首个价格版本可追溯 |
| 重复模型标识，或修改已有供应商标识 | 请求失败，原记录保留 |
| 停用一个模型 | 新轮次不可选择，历史记录仍可查询 |
| 一轮执行期间管理员更新费率 | 该轮继续按原价格，新轮次使用新价格 |
| 同时修改同一模型价格 | 版本号唯一，历史版本不被覆盖 |
| 输入负价格、NaN 或无穷值 | 校验失败，不写入价格版本 |
| 未配置 API Key 时发送消息 | 明确提示配置缺失，不产生供应商调用 |
