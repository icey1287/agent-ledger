# 资料与工具权限

## 功能范围

接收文字资料，提供限定的资料读取与检索工具，并按每轮执行控制授权。

## 功能要求

- **MAT-01 输入**：用户可将文本写入消息，或上传 UTF-8 TXT、可提取文字的 PDF。附件保留名称、类型和提取文本；不执行 OCR。无法解析、无可提取文本或不支持的文件返回明确错误。
- **MAT-02 资料范围**：模型可获得本对话已上传资料的目录；读取和检索仅覆盖同一用户、同一对话的资料。后续轮次可继续使用此前附件，无需重复上传。
- **MAT-03 工具行为**：`read_material` 按资料 ID 返回全文；`search_materials` 按关键词返回匹配片段和资料标识。指定其他对话的资料 ID 或任意本地路径不能获得内容。
- **MAT-04 授权粒度**：按“本轮执行＋工具”保存授权，读取与检索分别控制。用户可配置到期时间，并在执行期间撤销授权；有效期存在时须为带时区的未来时间。
- **MAT-05 执行前检查**：每次工具执行前检查授权是否存在、已撤销或到期；任何一项不满足都拒绝该次工具执行、记录原因并停止本轮后续执行。角色读取资料同样受检查约束。
- **MAT-06 历史资料授权**：访问历史附件使用本轮授权，不沿用上传时或上一轮的授权。撤销影响后续工具访问，不能撤回已经发送给模型或进入历史回复的内容。
- **MAT-07 工具边界**：附件内容作为数据处理，不得改变系统指令或增加工具权限；工具名和参数须通过后端校验。应用不另设文件大小、调用次数或 token 配额。

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 上传有效 TXT 和有文字的 PDF | 提取内容可由资料工具读取 |
| 上传损坏 PDF、仅图像 PDF或不支持的文件 | 明确失败，不把空文本作为有效资料 |
| 第二轮读取第一轮附件 | 在本轮已授权时成功，且不要求重复上传 |
| 第二轮未授权，或传入其他对话的资料 ID | 不返回资料内容 |
| 模型调用过程中撤销工具授权，随后模型请求该工具 | 工具被拒绝，本轮停止并保存拒绝记录 |
| 工具即将执行时授权已经到期 | 不执行工具，停止原因可见 |
| 附件声称可以忽略权限或读取外部文件 | 后端仍限制在预定义工具和授权范围内 |
