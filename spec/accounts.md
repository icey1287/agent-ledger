# 账号与访问控制

## 功能范围

提供用户名密码注册、登录、退出登录和会话识别；区分普通用户与管理员，隔离用户的对话、资料和执行记录。

## 功能要求

- **ACC-01 注册**：用户名唯一；重复注册返回明确错误。注册只能创建普通用户，客户端传入的角色不得赋予管理权限。
- **ACC-02 登录与会话**：凭正确用户名密码建立会话；凭据错误时统一提示用户名或密码错误。刷新页面保留有效登录状态；退出登录后该会话失效；失效会话访问受保护功能时要求重新登录。
- **ACC-03 数据隔离**：用户只能列出、读取和操作自己拥有的对话、消息、附件及执行记录。猜测其他用户的资源 ID 不得获得资源内容或操作权限。
- **ACC-04 管理员**：管理员通过独立初始化命令创建。管理员可管理模型和核实异常用量；普通用户不能访问这些功能。管理员通过普通对话接口访问数据时仍受所属用户检查约束。
- **ACC-05 凭据保护**：密码以哈希保存，会话令牌不以明文入库；API 不返回密码、模型密钥或会话凭据。已认证的写请求校验 CSRF 与请求来源。

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 首次注册与重复注册同一用户名 | 首次成功，重复请求失败且不创建第二个账号 |
| 注册时提交管理员角色 | 获得普通用户权限 |
| 错误密码登录 | 登录失败，不建立有效会话 |
| 登录后刷新，再退出并访问受保护接口 | 刷新保持登录；退出后的请求被拒绝 |
| 用户 A 请求用户 B 的对话、执行、停止或授权接口 | 不返回 B 的内容，不修改 B 的资源 |
| 普通用户请求模型管理或用量补录 | 权限拒绝 |
| 已登录但写请求缺少有效 CSRF 或来自不允许的来源 | 写入被拒绝 |
