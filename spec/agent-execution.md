# Agent 执行

## 功能范围

每轮用户消息由协调 Agent 处理，可自主选择资料工具、摘要角色和审核角色，完成回复并保存执行记录。

## 功能要求

- **EXEC-01 自主调度**：普通问答可直接回复；资料整理或核查按需要委派摘要、审核角色。协调者可调整顺序和重复调用，但只能使用预定义角色与工具，不能创建新角色或执行任意代码。
- **EXEC-02 模型一致性**：每轮固定一个选定模型，所有角色共用。通过 OpenAI 兼容接口进行真实调用，支持工具请求与供应商用量返回；生产路径不以模拟输出替代调用。
- **EXEC-03 后台执行**：每轮内部串行，页面关闭后仍可继续；不同对话可并发。同一轮只允许一次领取执行权，轮询或刷新不得重复启动执行。
- **EXEC-04 调用记录**：调用供应商前建立在途记录；响应后保存角色、请求标识、消息、原始用量和调用状态。角色委派及资料工具另有执行记录，能追溯所属轮次。
- **EXEC-05 用户停止**：停止请求阻止本轮继续调度；已经发出的模型调用仍接收结果并记录用量。该结果不得把用户已停止的执行改成成功完成。
- **EXEC-06 失败处理**：无有效消息、无效工具参数或供应商截断输出不能标记为成功；保存可获得的输出、用量及明确原因。只有完整最终回复且调用用量已确认，才能正常完成。
- **EXEC-07 未知结果**：超时、连接中断或其他导致结果与用量无法确定的异常停止本轮，进入待核实；不自动重试。具体记账规则由计费 spec 定义。
- **EXEC-08 服务中断**：重启后不恢复未完成执行；遗留在途调用进入用量待核实，其他未完成执行标为中断，保留已保存的结果与费用。

## 终止条件

| 条件 | 结果 |
| --- | --- |
| 最终回复完整，用量已确认 | 完成 |
| 已达到预算且仍需下一次调用 | 预算停止 |
| 工具授权不满足 | 权限停止 |
| 用户主动停止 | 用户停止，并等待在途调用结算 |
| 调用结果或用量不明 | 用量待核实 |
| 明确失败且没有未决用量 | 失败 |
| 服务中断且没有未决调用，或未知用量已补录 | 中断，不自动续跑 |

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 普通问题与需要摘要、审核的问题 | 前者允许直接回复；后者可调用固定角色并形成最终回复 |
| 模型请求未知工具或非法参数 | 不执行未授权行为，错误可追溯 |
| 多角色执行一轮消息 | 所有角色使用同一模型，执行顺序可查 |
| 调用进行中停止，随后供应商返回 | 保存实际用量，保留停止状态，不继续调度 |
| 供应商返回截断内容 | 保留内容和已知用量，标记未完成 |
| 超时或进程中断后重启 | 不重复调用，未决用量进入待核实 |
