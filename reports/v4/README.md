The 31-page report follows requirements → ER relationships → relational mapping → normalization → implementation → verification. Eight business rules map to 15 tables and 24 foreign-key relationships.

The evidence archive includes the v4 report only. Earlier test logs and source hashes are retained as historical evidence; `team-tests.txt` records the current 48 passing cases, and `AgentDesk-source-v3.zip` is the tested application source snapshot (the source version differs from the report version). Live demonstrations use configured demonstration rates, not provider invoices.

This publication does not change the original experiments or their timestamps. The report describes the pre-publication local snapshot; its statements about unpublished changes describe that capture time. Current source is now also available in this repository.

The archive contains a SHA-256 manifest. Credentials, runtime databases, private uploads and account sessions are excluded.
